| 5 | 2026-10-27 | Sessions | Server-side sessions in `auth_session` behind an HttpOnly `fs_session` cookie (SHA-256 of a 256-bit token stored), CSRF via `XSRF-TOKEN` cookie → `X-XSRF-TOKEN` header (token loaded on every request so the cookie is always present), instead of the reference's bearer token in localStorage.
