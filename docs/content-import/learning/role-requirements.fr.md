# Conditions pour les rôles dans foodsharing

*État : 08.11.2026 - 00h00*

Il existe différents rôles et tâches chez foodsharing. Cela commence par les foodsharers (c’est-à-dire nous tous et toutes), et il y a d’autres rôles qui impliquent un peu plus de responsabilité et pour lesquels il faut donc remplir d’autres conditions. Elles sont réunies dans cet article.

### <a id="allgemeines-fuer-alle-rollen"></a>Généralités pour tous les rôles

1. Sur demande, les personnes reçoivent chez foodsharing les statuts suivants et donc la possibilité d’exercer les rôles correspondants, si elles remplissent les conditions indiquées pour chacun.
2. Si une condition n’est plus remplie, le statut correspondant est retiré ; si la condition est de nouveau remplie, le ou la foodsaver ou foodsharer retrouve le statut.

### <a id="voraussetzungen-fuer-foodsharer-innen"></a>Conditions pour les foodsharers

- avoir au moins 18 ans
- compte sur la plateforme foodsharing
- acceptation des bases de foodsharing
- consentement à la déclaration de protection des données
- pas de carton rouge

### <a id="voraussetzungen-fuer-unverifizierte-foodsaver-innen"></a>Conditions pour les foodsavers non vérifié·es

- foodsharer
- quiz foodsaver réussi
- confirmation de l’accord juridique (Allemagne, Autriche) pour les foodsavers
- pas de carton jaune-rouge dont la durée n’est pas encore écoulée

### <a id="voraussetzungen-fuer-verifizierte-foodsaver-innen"></a>Conditions pour les foodsavers vérifié·es

- foodsharer non vérifié·e
- données correctes dans le profil : nom, adresse, date de naissance, photo représentative
- au moins 3 collectes d’introduction réussies en 6 mois
- pas de carton jaune dont la durée n’est pas encore écoulée

### <a id="voraussetzungen-fuer-betriebsverantwortliche"></a>Conditions pour les responsables de commerce

- foodsaver vérifié·e
- quiz pour responsables de commerce réussi
- consentement à la notice de protection des données (complément à la déclaration de protection des données)
- consentement à l’accord juridique pour responsables de commerce (complément à l’accord juridique)

### <a id="voraussetzungen-fuer-botschafter-innen"></a>Conditions pour les ambassadeur·rices

- foodsaver vérifié·e depuis au moins 6 mois
- pas de conséquences pour des violations de règles pertinentes qui ne peuvent pas encore être effacées
- responsable de commerce
- quiz pour ambassadeur·rices réussi
- au moins 30 collectes chez foodsharing
- élu·e démocratiquement dans le district selon les « règles pour les élections des ambassadeur·rices » de foodsharing
- un entretien d’accueil avec l’équipe d’accueil des ambassadeur·rices
- Durant les 2 premières années après la création d’un district, le nombre de collectes, la durée comme foodsaver vérifié·e et l’élection ne sont pas exigés des ambassadeur·rices.
