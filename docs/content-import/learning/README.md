# Learning chapters (C1)

The foodsharing-Grundlagen from the owner's wiki texts (`../wiki/*.wiki`), as shown under "Wissen" (`/learn`).

| File | Made by |
|---|---|
| `<key>.de.md` | generated by `server/scripts/gen-learning-chapters.py` from the wiki file; do not edit |
| `<key>.en.md`, `.fr.md`, `.it.md`, `.gws.md` | translated by hand (machine translation) from the German file |

Each file starts with `# Title`, a blank line and the Markdown body. Translations keep every `<a id="…"></a>` anchor
and every link target of the German text (the converter fails otherwise); only the visible text changes.

`python3 server/scripts/gen-learning-chapters.py` writes the German files and the non-seed changesets
`195-content-learning-basics.yaml` (chapters) and `196-legal-agreement-wiki.yaml` (the Rechtsvereinbarung as the
binding `LEGAL_AGREEMENT`, version `2026-11`). Re-running it gives identical files. Both changesets insert only when
their ids are free, so later CMS edits are never overwritten.

**Never regenerate an applied changeset with different content** (Liquibase checksums). For a newer wiki version:
the converter refuses to overwrite a changeset with different content (`--force` only for one never released); change `CHAPTERS_FILE`/`LEGAL_FILE` (and the legal `LEGAL_VERSION`) to new numbers, decide whether the new changeset
updates existing rows, and keep the old files unchanged.

`Regelverletzungen_-_Erläuterungen.wiki` is only a redirect today; the converter skips it (key
`rule-violations-explained`, group MORE, optional) until the owner supplies the text.
